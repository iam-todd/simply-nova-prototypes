# Ticket

The spread card, drawn as a counter ticket: numbered stub, photo, name, one-line pitch, optional status, price and action.

**Consumer provides:** number, serving line ("Feeds 4–6"), image, name, one sentence, price, and optionally a Tag.

**Rules**
- White (`sn-raised`) — the only raised surface on the homepage.
- Action is `.btn-2` so the hero keeps the page's only filled button; sold out swaps to the disabled primary and fades the price.
