# CateringHeadline

Display headline with photo tiles set inline at cap height, interrupting the line the way a word would; the closing phrase drops to DM Sans italic lowercase.

**Rules**
- Tiles are sized in em (`.w1`–`.w3`), so they scale with the type; hidden from screen readers.
- The italic aside is a voice change, not a fourth face.
- Use once per page at most.
