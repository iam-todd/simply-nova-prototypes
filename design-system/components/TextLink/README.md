# TextLink

Every link carries a 1.5px teal underline at rest; the underline never comes off.

**Rules**
- `sn-teal` on cream and white, `sn-teal-onink` on espresso — never crossed.
- Hover and focus turn text and underline `sn-hover-ink` (clay).
- `.plain` removes the underline only on whole-card links (category tile, lineup item) where the card itself signals it.
- Link heads (rail items) use a 2px underline.
