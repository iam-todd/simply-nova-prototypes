Which modules go on which page

One set of modules, built once. Rules decide what shows on each product page. Switch the page type and watch what drops out. The panel on the right is what you'd see on a product's edit screen.

The four rules

Always

On every product page. Locked in the panel, so nobody switches it off by accident.

Page type

The default comes from the page-type column in the catalogue plan. Tick or untick to change it for one product.

Needs data

Turned on, but it only appears once the content exists. No empty boxes, no "be the first to review".

Hand-picked

Off unless you choose it for that product. The statement lives here so it stays rare.

Module order is fixed and the same on every page; the panel only turns modules on and off. Product names, counts and copy are stand-ins. Schema is built from what actually shows, so a hidden module never leaves markup behind.
