# Well

The image frame and placeholder: `sn-status-bg` fill, hairline border, 12px radius.

**Consumer provides:** a photo or loop. Until one exists, a mono caption naming the shot ("Platter overhead", "still 4:5").

Aspect ratios in use: 4:3 default, 16:9 `.wide` (hero loop), 4:5 (category tiles, lineup, mega-menu features at 400×520), 5:3 (holiday rail), 1:1 (gallery, Instagram). On hover inside a tile the border goes clay.
