# Tag

Status chips in two tiers: scarcity (clay tint) and absent (faint espresso).

**Consumer provides:** a short uppercase phrase with a real date or count.

**Rules**
- `.tag` = scarcity you can still act on: `sn-clay-tint` fill, `sn-clay-ink` text. "Two left for Sunday", "Orders close 8 April".
- `.tag.out` = absence, which is not urgent: `sn-status-bg` fill, `sn-status-ink` text. "Back Thursday", "Back when the run allows".
- Never on anything clickable. Never decorative ("New!", "Popular").
